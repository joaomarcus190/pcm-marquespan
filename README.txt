PCM MARQUESPAN 3.1 - MOBILE + EQUIPE

Execute no computador servidor:
1. Instale Python 3.10+.
2. Abra o terminal nesta pasta.
3. pip install -r requirements.txt
4. python app.py
5. No servidor: http://localhost:5000
6. Descubra o IPv4 com ipconfig (Windows) ou hostname -I (Linux).
7. No celular conectado à MESMA rede Wi-Fi, acesse http://IP_DO_SERVIDOR:5000
   Exemplo: http://192.168.1.100:5000

Se não abrir: confira Wi-Fi, firewall permitindo Python na rede privada, terminal aberto e IP correto. Não use localhost no celular.
